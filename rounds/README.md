# Rounds

Each page explains one round of a DevOps or SRE interview loop: what the interviewer measures, a method for answering, and a short example. Start with the interview loop page if the rounds are not yet known.

| Round | Page | The question behind the round |
|---|---|---|
| The whole loop | [Interview loop](interview-loop.md) | Which rounds will appear, and in what order? |
| Troubleshooting | [Troubleshooting](troubleshooting.md) | Can the candidate find a fault with a method? |
| Linux and networking | [Linux and networking](linux-and-networking.md) | Does the candidate know how the system behaves? |
| Design | [SRE system design](sre-system-design.md) | Can the candidate design for failure, capacity, and rollout? |
| Coding | [Coding and scripting](coding-and-scripting.md) | Can the candidate automate a practical task? |
| Incidents | [Incident response](incident-response.md) | Can the candidate lead when production is failing? |
| Behavioral | [Behavioral](behavioral.md) | How has the candidate acted in real situations? |

The concepts that these rounds draw on are in [concepts](../concepts/README.md). Question lists and reference tables are in [cheat sheets](../cheat-sheets/README.md).
