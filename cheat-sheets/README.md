# Cheat Sheets

These pages are for review in the last days before an interview. Each one is a table or a list that can be read in a few minutes.

| Page | Use it for |
|---|---|
| [Question bank](question-bank.md) | About 60 questions grouped by round, each with a pointer to the answer |
| [Linux commands for troubleshooting](linux-commands-for-troubleshooting.md) | Matching each command to the question it answers |
| [DevOps vs SRE](devops-vs-sre.md) | Understanding which role and which loop you are preparing for |
| [Availability numbers](availability-numbers.md) | Quoting allowed downtime for a target without calculating |
| [Common mistakes](common-mistakes.md) | Checking your practice answers against ten frequent errors |
| [Four-week plan](four-week-plan.md) | Scheduling preparation week by week |

The reasoning behind these summaries is in [rounds](../rounds/README.md) and [concepts](../concepts/README.md).
